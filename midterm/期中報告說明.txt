期中報告說明
完成課程所需要的條件
物件導向程式設計
期中小型專案：跨課程知識應用與 Python 工具程式開發
作業類型： 個人專案
開發語言： Python
預估開發時間： 一天內完成（約 4～8 小時）
作業內容： 自行定義題目、開發工具程式、測試與專案報告

一、作業目的
在過去及目前修習的課程中，同學已經學習許多數學、資訊及其他專業知識。

本次作業希望同學選擇一個學過的知識、公式、演算法或計算問題，利用 Python 開發一個簡單且實用的工具程式。

透過本次專案，同學將練習：

自行發現問題並定義專案題目。

將課堂學過的知識轉換成程式。

使用 Python 函式、迴圈、條件判斷及資料結構完成程式。

將程式拆解成容易理解的功能。

透過不同測試資料確認程式正確性。

練習整理程式開發成果並進行專案報告。

本次作業重點是程式設計基礎的整合應用，不要求使用 class 或其他尚未教授的物件導向語法。

二、專案題目要求
1. 題目必須與修習過的課程相關
同學須從目前或過去修習的課程中，選擇一個適合使用 Python 解決的問題。

例如：

數值分析：牛頓逼近法

線性代數：矩陣運算、反矩陣

微積分：數值積分

統計學：平均數、變異數、標準差

離散數學：最大公因數、質數判斷

演算法：排序與搜尋

資料結構：串列資料處理

其他課程中的公式、演算法或計算問題

題目不限定上述範例，但必須能說明與哪一門課程、哪個知識或方法有關。

2. 專案規模
本次作業為小型工具程式，預期一天內可以完成。

不需要開發大型系統，也不要求圖形化操作介面。

建議選擇一個明確的問題，將主要功能完整實作即可。

3. 程式必須具有實際功能
程式至少應包含：

輸入（Input）： 使用者輸入數值、參數或資料。

處理（Process）： 透過公式、演算法或程式邏輯完成計算。

輸出（Output）： 顯示計算結果或分析結果。

程式必須能根據不同輸入產生對應結果，不可只顯示預先寫好的固定答案。

三、Python 程式設計要求
本次專案以目前已學過的 Python 語法為主。

程式設計概念	應用方式
函式 def	將主要計算功能設計成函式
參數與 return	傳入資料並回傳計算結果
if / elif / else	進行條件判斷
for / while	執行重複計算或迭代
list	儲存與處理多筆資料
dict	組織具有不同欄位的資料
math 模組	使用數學函式進行計算
字串操作	處理文字資料與輸出格式
基本要求
至少自行定義一個具有實際功能的函式。

使用函式參數接收資料，並依需求使用 return 回傳結果。

依照題目需求使用迴圈、條件判斷或串列等功能。

主要功能不可只針對單一測試資料寫出固定答案。

程式應有適當註解及清楚的變數名稱。

至少使用兩組不同測試資料驗證結果。

不要求每個專案都使用所有語法。請根據題目需求選擇適當的程式設計方法。

五、如何定義自己的專案？
請依照以下步驟進行。

步驟一：選擇相關課程
例如：數值分析。

步驟二：選擇學過的知識
例如：牛頓逼近法。

步驟三：定義工具功能
例如：開發一個能夠利用牛頓逼近法，計算指定方程式近似根的程式。

步驟四：決定輸入與輸出
輸入：

初始猜測值

誤差容許值

最大迭代次數

輸出：

近似根

迭代次數

是否達到收斂條件

步驟五：規劃程式邏輯
例如：

取得使用者輸入。

計算函數值與導數值。

利用牛頓逼近公式更新近似值。

重複執行直到符合停止條件。

回傳並顯示計算結果。

步驟六：規劃函式
例如：

def f(x):
    return x**2 - 2

def df(x):
    return 2 * x

def newton_method(x0, tolerance, max_iter):
    # 在這裡完成迭代計算
    pass
此範例僅示範如何拆解函式，實際計算內容須自行完成。

步驟七：準備測試資料
至少準備兩組不同輸入，確認程式能得到合理且正確的結果。

十一、作業注意事項
題目須與目前或過去修習的課程相關。

專案以一天內可以完成為原則。

使用 Python 開發。

十二、給同學的提醒
本次專案不是要開發複雜的軟體，而是希望大家思考：

「我曾經在其他課程學過什麼知識？能不能使用 Python，將它變成一個實際可使用的工具？」

例如：

學過牛頓逼近法，就設計自動求根工具。

學過矩陣運算，就設計矩陣計算工具。

學過統計學，就設計資料統計工具。

學過排序演算法，就設計排序工具。

題目不需要很難，但必須能夠清楚說明問題、正確完成計算，並透過測試確認結果。

題目可以簡單，但功能要完整；程式可以精簡，但邏輯要清楚；報告不必複雜，但必須能夠說明自己的設計。
