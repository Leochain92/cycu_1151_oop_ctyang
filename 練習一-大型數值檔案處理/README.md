# 練習一：大型數值檔案處理 - BCSSTK25 矩陣分析與求解

## 1. 矩陣基本背景
- **矩陣名稱**：BCSSTK25 (來自 Harwell-Boeing Collection, BCSSTRUC3 矩陣集)
- **工程背景**：美國西雅圖 76 層摩天大樓 (Columbia Center) 之結構工程剛度矩陣 (Stiffness Matrix)。
- **用途**：結構力學振動分析、特徵值問題 (固有頻率與振動模態)、以及結構受力變形之線性系統求解 ($Kx = f$)。
- **資料來源**：[NIST MatrixMarket - BCSSTK25](https://math.nist.gov/MatrixMarket/data/Harwell-Boeing/bcsstruc3/bcsstk25.html)

## 3. 老師提示深入探討：「為什麼稀疏矩陣的反矩陣不一定是稀疏矩陣？」

### (1) 口語觀念解析：「除 I 跟 value」
- 口語中的「I跟value」即為 **Eigenvalue (特徵值)** 及 **Eigenvector (特徵向量)**。
- 該矩陣在結構力學主要用於求解最低固有頻率振態（即廣義特徵值問題 $Kx = \lambda Mx$ 或標準特徵值問題 $Kx = \lambda x$）。

### (2) 稠密填充現象 (Dense Fill-in Phenomenon)
- **稀疏矩陣的逆矩陣在絕大多數情況下是完全稠密的 (Dense)！**
- 實驗驗證：
  我們透過稀疏 LU 分解抽樣檢驗 $A^{-1}$ 的各欄向量 ($A^{-1} e_j$)：
  - 第 0 欄向量非零比例：**99.42 %**
  - 第 3000 欄向量非零比例：**99.42 %**
  - 第 7719 欄向量非零比例：**99.40 %**
  - 第 12000 欄向量非零比例：**99.28 %**
  - 第 15438 欄向量非零比例：**99.26 %**
- **結論**：
  雖然原矩陣 $A$ 有 $99.89\%$ 是 0，但其反矩陣 $A^{-1}$ 超過 $99\%$ 的元素皆非零。
  - 若試圖以稀疏格式儲存 $A^{-1}$，因額外維護索引指針，記憶體會暴增至 **2.7 GB** 以上（比密集矩陣的 1.78 GB 還大）。
  - 若直接求取逆矩陣，需要 $O(N^3) \approx 3.68 \times 10^{12}$ 次浮點運算，耗時極長。
  - **數值線性代數鐵律**：永遠使用分解法（如 LU / Cholesky）解 $Ax = b$（僅需 0.35 秒），絕不直接顯式求逆 $x = A^{-1}b$。

## 4. 計算求解成果摘要

執行物件導向求解程式 `matrix_solver.py` 得到之結果：

### A. 前 6 階最低固有振動模態 (Eigenvalues)
使用 ARPACK Lanczos 演算法 (Shift-Invert 模式，$\sigma = 0$)：
- **計算耗時**：0.54 秒
- **模態 1**：$\lambda_1 = 2.401570 \times 10^2$ (固有頻率 $f_1 \approx 2.4664\text{ Hz}$)
- **模態 2**：$\lambda_2 = 2.478511 \times 10^2$ (固有頻率 $f_2 \approx 2.5056\text{ Hz}$)
- **模態 3**：$\lambda_3 = 3.413676 \times 10^2$ (固有頻率 $f_3 \approx 2.9406\text{ Hz}$)
- **模態 4**：$\lambda_4 = 1.434961 \times 10^3$ (固有頻率 $f_4 \approx 6.0289\text{ Hz}$)
- **模態 5**：$\lambda_5 = 2.201430 \times 10^3$ (固有頻率 $f_5 \approx 7.4675\text{ Hz}$)
- **模態 6**：$\lambda_6 = 2.848176 \times 10^3$ (固有頻率 $f_6 \approx 8.4938\text{ Hz}$)

### B. 線性系統求解 ($Ax = b$)
使用 SuperLU 稀疏直接法求解器：
- **計算耗時**：0.35 秒
- **相對殘差**：$2.52 \times 10^{-16}$ (達到機器浮點數極限精度)
